# 小学生时钟乐园

一个给小学生学习「认识时间」的网页，包含**圆盘钟表**、**数字钟表**和**闯关练习**。
纯 HTML / CSS / JavaScript 实现，无任何依赖，双击打开就能用。

## 打开方式

直接双击 `index.html`，或在浏览器地址栏打开：

```text
file:///Users/bing/Documents/workspeace/learning-tools/kids-clock/index.html
```

也可以在本目录启动一个本地服务器：

```bash
cd learning-tools/kids-clock
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 功能

### 圆盘钟表
- 60 格刻度、1~12 数字、5~60 分钟数字，可开关显示
- 蓝色短粗**时针**、绿色长**分针**、红色细长**秒针**，可在钟面上显示指针名称
- 拖动任意指针即可拨钟，拖动时时间连续变化，自动处理「60 秒进 1 分、60 分进 1 时」
- 指针名称、分钟数字、24/12 小时制三个显示开关

### 数字钟表
- 大号数字时间 + 上午/下午/晚上时段
- 中文读法（如「上午 8 时零 5 分 30 秒」）
- 实时解释三根指针分别指向哪里、表示多少

### 三种模式
- **看现在**：实时走时，秒针平滑转动，数字钟同步更新
- **动手拨**：选择时针/分针/秒针后拖动钟面，或用 ± 按钮微调；支持整点、半点、现在、随机
- **闯关练习**：每轮 6 题，涵盖
  - 看钟读时间（四选一）
  - 认指针（时针 / 分针 / 秒针）
  - 进率换算（1 时 = 60 分、1 分 = 60 秒、半小时、一刻钟……）
  - 动手拨钟（按题目把钟拨到指定时间，带提示与讲解）
  - 计分、星级和错题讲解

### 时钟小课堂
1. **认识三根针**：特点、走 1 格/1 圈表示多少，一键在钟上高亮对应指针
2. **指针的关系**：秒针走 1 圈 = 分针走 1 小格；分针走 1 圈 = 时针走 1 大格，并带动画演示
3. **进率换算**：进率卡片 + 可交互的「时/分/秒 → 分/秒」换算器
4. **读写时间**：读钟四步口诀 + 4 个钟面示例（整时、半时、零几分、几时几分）

## 说明
- 桌面端和手机端均有适配，手机上钟面会缩小、练习选项更易点按。
- 拖拽指针需要鼠标或触摸操作；键盘用户可以使用「动手拨」里的 ± 按钮。
- 页面不依赖网络，所有图形均为 SVG / CSS 绘制。
