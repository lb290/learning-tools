# 学习工具

专门用来放「给小学生做的学习小工具」的文件夹。每个工具是一个独立的小页面，纯前端实现，双击 `index.html` 就能打开，不需要安装任何东西。

## 已有工具

| 工具 | 说明 | 入口 |
| --- | --- | --- |
| 小学生时钟乐园 | 圆盘钟表 + 数字钟表，学习时针、分针、秒针、指针关系、时间表示和进率换算，带闯关练习 | [kids-clock/index.html](kids-clock/index.html) |
| 圆的乐园 | 小学数学「圆」互动学习：圆的概念、圆周率、1π~100π、半径直径、圆周长、圆面积、扇形、阴影面积；含演示动画、知识讲解、动手实验和闯关测试 | [kids-circle/index.html](kids-circle/index.html) |

## 约定

- 每个工具一个子目录，目录内自带 `index.html` 和 `README.md`。
- 不依赖网络和第三方库，方便离线使用、直接拷贝分享。
- 优先适配手机和平板，方便孩子在触屏上操作。
